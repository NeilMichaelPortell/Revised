# Approved Administrative Activity

Category: NORMAL

## Description
Approved administrative activity may include managed updates, known backup jobs, and support tasks tied to documented operational processes.

## Risk interpretation
Administrative activity is not automatically risky. Risk increases when the activity is undocumented, uses suspicious tools, or changes security controls unexpectedly.

## Expected indicators
- managed_update
- known_backup
- helpdesk_workflow

## Example scenarios
- A known backup task runs without being modified.
- A helpdesk technician performs a documented password reset.
- Software is updated through an approved management channel.
