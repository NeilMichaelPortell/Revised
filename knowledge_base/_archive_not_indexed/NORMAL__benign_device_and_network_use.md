# Benign Device And Network Use

Category: NORMAL

## Description
Benign endpoint use can include approved peripherals, trusted network profiles, and ordinary downloads from approved sources.

## Risk interpretation
Peripheral and network activity should stay low risk when it is approved, expected, and not followed by suspicious process execution or data staging.

## Expected indicators
- approved_peripheral
- normal_device_use
- trusted_network

## Example scenarios
- A user connects an approved keyboard and headset.
- A managed laptop remains on the domain network profile.
- A routine approved download occurs without suspicious execution.
